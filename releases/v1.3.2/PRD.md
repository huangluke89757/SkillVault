# SkillVault v1.3.2 产品需求文档（PRD）

- 版本：v1.3.2
- 日期：2026-11-15
- 类型：功能补全（已安装列表批量操作，Issue #6）
- 关联：`releases/v1.3.2/RELEASE-CHECKLIST.md`、Issue #6、PR #7

## 一、问题（为什么要改）

「已安装」列表已有批量收藏与批量加入集合，但 Agent 适配只能单向新增：选中多个 Skill 后，只能把它们「适配到某个 Agent」，无法批量取消。用户一次清理多个 Skill 的某个 Agent 副本时，只能逐条点。

## 二、目标与非目标

### 目标
- G1：一次选中多个 Skill，批量启用或取消指定 Agent 的适配
- G2：按 Agent 汇总所选 Skill 的当前状态（全部 / 部分 x/y / 未适配），避免误操作
- G3：取消适配只移除 Agent 副本，母本 Skill 文件不受影响

### 非目标
- 不改批量收藏与批量集合（已有）
- 不改 IPC、数据结构与持久化格式
- 不做「按 Agent 全量清空」等破坏性入口

## 三、方案

把批量操作栏的「适配到 Agent」下拉改为「调整适配」按钮，打开对话框：

| 区域 | 行为 |
|---|---|
| 每个可适配 Agent 一行 | 显示 logo、名称、当前状态（全部已适配 / 未适配 / x/y） |
| 勾选 | 目标为全部适配；只提交被用户改过的 Agent |
| 取消勾选 | 目标为全部取消；只移除该 Agent 下的副本 |
| 应用 | 逐条调用既有 `addToAgent` / `removeFromAgent`，完成后重扫列表并提示「新增 x / 取消 y / 失败 z」 |

`universal` 与共享 Skill 目录的 Agent 不进入对话框（沿用旧下拉的过滤规则）。

## 四、验收标准

- [ ] 选中 3 个均已适配 Claude Code 的 Skill，取消勾选并应用：列表适配数 5→2，提示「取消 3 个适配」
- [ ] 部分适配（x/y）显示 mixed 态，勾选后补齐缺失适配
- [ ] 取消适配后母本 Skill 文件仍在
- [ ] 单测通过（82 passed / 1 skipped）
- [ ] `electron-vite build` 通过

## 五、风险与取舍

| 风险 | 影响 | 处置 |
|---|---|---|
| 批量取消写文件系统，中途失败 | 中 | 逐条捕获失败并计数，不中断其余条目；结果提示失败数 |
| 与单条取消的语义不一致 | 低 | 复用同一 IPC（`removeFromAgent` + `createSkillRemovalRequest`） |
| 部分适配时误勾选导致补齐 | 低 | 对话框实时显示「将全部适配 / 将取消适配」与变更计数 |

## 六、后续（v1.4 候选）

- 批量操作栏收纳（收藏 / 适配 / 集合合并为菜单）
- Agent 副本版本不一致检测
