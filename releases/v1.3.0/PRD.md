# SkillVault v1.3.0 产品需求文档（PRD）

- 版本：v1.3.0
- 日期：2026-09-28
- 状态：已实现待发布
- 关联：`releases/v1.3.0/RELEASE-CHECKLIST.md`、对标产品 ColaSkill（colaskill.com/zh）

## 一、背景与问题

对标 ColaSkill 详情页发现三个体验差距：

1. **介绍只有英文**：SkillVault 市场 9 万+技能的 SKILL.md 几乎全英文，中文用户看介绍要靠猜；ColaSkill 每个技能都有中文标题 + 中文简介。
2. **创作者不可见**：看不到技能是谁写的，信任感弱；ColaSkill 有头像 + 作者名 + 认证标记。
3. **仓库热度不可见**：不知道技能背后仓库的星标数，难以判断成熟度；ColaSkill 展示 GitHub Stars 并可点击跳转。

## 二、目标与非目标

### 目标
- G1：详情页提供中文简介（标题 + 描述英译中），标注「机翻」以区分人工翻译。
- G2：详情页标记创作者（GitHub 头像 + @作者），点击直达原仓库。
- G3：展示 GitHub Stars，点击直达原仓库。
- G4：**保留详情页全部原有模块**（意图介绍、三通道安装、收藏、中英切换、SKILL.md 原文渲染）。

### 非目标（本期不做）
- 不做全文翻译（只译标题 + 描述；SKILL.md 正文保留原文）。
- 不做人工翻译/策展机制（ColaSkill 是人工策展，SkillVault 是 9 万+长尾，成本不允许）。
- 不做创作者认证体系。
- 不引入付费翻译 API（用免费匿名端点 + 缓存 + 降级）。

## 三、方案设计

### 3.1 汉化链路（学 ColaSkill 的呈现，用机器翻译实现）
```
SKILL.md → 提取 front matter name/description（兜底：正文首段）
        → 已是中文？直接展示
        → 本地缓存命中（localStorage，30 天 TTL）？直接展示
        → 主进程 IPC（skills:translate-text，net.fetch 跟随系统代理）
            端点链：MyMemory（匿名免费，单次 ≤500B，按句分块 ≤400 字符）
                 → Google gtx（非官方免费，兜底）
        → 成功：展示 + 写缓存；失败：提示「暂时无法翻译，可切 EN」
```
关键决策：**翻译走主进程**——渲染层直连翻译 API 会撞 CORS 与 CSP，且 `net.fetch` 跟随系统代理，对国内网络环境更稳。

### 3.2 创作者与 Stars
- 创作者行：`https://github.com/<owner>.png` 头像（CSP `img-src https:` 已放行）+ `@owner`，整行点击直达 `github.com/<owner>/<repo>`。
- Stars：渲染层直取 `api.github.com/repos/<source>`（CSP 已放行且该域支持 CORS），localStorage 缓存 7 天，规避匿名 60 次/小时限额；拉取失败不展示，不留空壳。

### 3.3 UI 布局（新增不替换）
| 区域 | 新增 | 保留 |
|---|---|---|
| Meta 区 | 创作者行（头像 + @作者 + ⭐Stars） | source、installs 行 |
| 技能介绍区 | 「中文简介」卡片（标注机翻，含加载/失败态） | 是什么/有什么用/怎么用 模板、复制提示词 |
| 其他 | — | 三通道安装、收藏、中英切换、SKILL.md 原文 |

## 四、验收标准

- [ ] 中文模式下详情页出现「中文简介」卡片，内容为 SKILL.md 标题/描述的中文译文
- [ ] 英文模式下不出现该卡片（原文即英文）
- [ ] 断网或翻译端点失败时显示降级提示，页面其余功能不受影响
- [ ] 创作者头像 + @作者 可见，点击打开原仓库
- [ ] Stars 显示数字（如 5.3K），点击打开原仓库；重复打开不重复请求（缓存）
- [ ] `tsc --noEmit` 无错、构建通过、主包体积不回升（655 kB）

## 五、风险与取舍

| 风险 | 影响 | 处置 |
|---|---|---|
| 免费翻译端点在国内不可达或不稳定 | 中 | 端点链降级 + 30 天缓存 + 失败提示可切 EN；后续可评估接入本地 LLM |
| MyMemory 匿名配额（约 5000 词/天/IP） | 低 | 按需触发（打开详情才译）、缓存复用、分块 ≤400 字符 |
| api.github.com 匿名限额 60 次/时/IP | 低 | 7 天 localStorage 缓存；超限不展示 |
| front matter 解析覆盖不全（非标准 YAML） | 低 | 逐行解析 + 正文首段兜底；解析失败直接降级提示 |

## 六、指标（可观测性建议，本期仅埋点建议不做后台）
- 中文简介卡片曝光率、翻译成功率、缓存命中率（console 埋点即可）
- 创作者行 / Stars 点击率（可作为下一版是否深化创作者体系的依据）

## 七、后续演进（v1.4 候选）
- `skillvault://install/<skillId>?agents=...` 深链协议（融合方案 2 核心，自 v1.2 起持续后置）
- 收藏列表页 / 「只看收藏」筛选
- 接入本地 LLM 做更高质量的介绍翻译（含正文摘要）
- README 截图刷新
