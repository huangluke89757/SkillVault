# SkillVault v1.2.0 产品需求文档（PRD）

- 版本：v1.2.0
- 日期：2026-09-22
- 状态：已实现待发布
- 关联：`releases/v1.2.0/RELEASE-CHECKLIST.md`、`tasks/plan.md`

## 一、背景与问题

1. **安装通道单一**：v1.1.0 只有「应用内点击直装」一条路径，技能无法离开应用被安装。
2. **行业趋势变化**：对标 DeepSkill、SkillHub，安装入口正从「人点按钮」转向「口令驱动、Agent 自助安装」——人只复制一句话，下载 / 解压 / 目录路由全交给 Agent。
3. **缺少收藏**：市场技能浏览后无法留存，用户下次要重新搜索。
4. **前端包体积偏大**：主 chunk 1.90 MB，CodeMirror 等重依赖被打进启动路径。

### 系统视角（存量-流量）
- 存量：可安装技能池（9 万+）、已装技能、收藏列表。
- 当前瓶颈：**流出端**（安装转化）只有一条管道，且这条管道只在应用内存在。
- 增强回路缺口：装得越多 → 收藏与回搜越多 → 复用越多 → 再安装。收藏是这条回路缺失的一环（装完就失联）。

## 二、目标与非目标

### 目标
- G1：让技能能「离开应用」被安装（口令通道）。
- G2：保留并放大 SkillVault 的桌面端家底（symlink 路由、同名冲突处理、多 Agent 目标）。
- G3：补齐收藏存量，形成「浏览 → 安装 → 收藏 → 复用」回路。
- G4：降低前端启动加载体积。

### 非目标（本期不做）
- 不做 `skillvault://` 深链协议（融合方案 2 的核心，需要主进程注册，后置到 v1.3）。
- 不做自有 CLI（CLI 通道复用生态既有 `npx skills add`，避免虚构命令）。
- 不做收藏列表页 / 收藏筛选（仅详情页入口 + 持久化）。

## 三、方案设计（融合方案 1 · 详情集成式）

### 3.1 信息架构
| 位置 | 能力 | 说明 |
|---|---|---|
| 列表卡片 | 复制口令（轻量按钮） | 融合方案 B 的唯一落点：卡片右上角「复制口令」 |
| 详情弹窗 | 三通道安装面板 | 融合方案 A：本机直装为主 + 口令 / CLI / Zip 为次 |
| 详情弹窗头部 | 收藏（心形） | 仅详情页提供，列表卡片不出现 |

### 3.2 口令协议
```
请安装「<技能名>」技能（<owner/repo>）：根据 https://github.com/huangluke89757/SkillVault/blob/main/INSTALL.md 的说明，把该技能安装到 <AgentA>、<AgentB>。
```
- 未选目标 Agent：口令改为让 Agent 先询问用户要装到哪个 Agent。
- 口令随所选 Agent **动态生成**（选中谁，口令里就写谁）。

### 3.3 三通道
1. **本机直装**（主）：保留现有 `installSkill` 链路 → 中央仓库 + symlink 路由 + 冲突 detach/archive。
2. **复制安装口令**（推荐）：发给任意 Agent 自助安装。
3. **CLI 命令**：`npx skills add <owner/repo>`（生态既有命令）。
4. **Zip 包**：`https://github.com/<owner>/<repo>/archive/refs/heads/main.zip`，手动解压兜底。

### 3.4 收藏
- 存储：复用既有 SQLite `favorites(skill_name)` 表，键用命名空间 `market:<source>/<skillId>`，**不加表、不加 IPC**。
- 交互：详情页头部心形按钮，`aria-pressed` 反映状态，写入后即时回显。

### 3.5 体积重构
- Home 路由改为 `lazy`（移出 react-window / marked / 页面代码）。
- `SkillEditor`（CodeMirror）改为进入编辑时动态 import（用「动态导入 + 条件渲染」而非 `React.lazy`，规避 lazy 不透传 ref 的问题）。

## 四、验收标准

- [ ] 列表卡片点「复制口令」→ 剪贴板拿到带目标 Agent 的口令，且不触发进入详情
- [ ] 详情页切换 Agent → 口令文本同步变化
- [ ] 详情页三通道四个入口均可用（直装 / 复制口令 / 复制命令 / 下载 zip）
- [ ] 收藏按钮点击后状态持久化，重启应用仍保留
- [ ] `npm run build` 通过、`tsc --noEmit` 无错
- [ ] 主 chunk ≤ 0.7 MB（实测 0.64 MB）

## 五、风险与取舍

| 风险 | 影响 | 处置 |
|---|---|---|
| 卡片原为 `<button>`，嵌套按钮非法 | 中 | 根元素改 `div`（role=button + 键盘可达），复制按钮 `stopPropagation` |
| Zip 链接按 `main` 分支推断 | 低 | 默认分支非 main 的仓库会 404；已在文档标注，后续可用 GitHub API 取默认分支 |
| CLI 非自有命令 | 低 | 有意取舍：不虚构 `skillvault add`，避免用户复制后失败 |
| 安装包体积下降有限 | 中 | Electron 运行时占约 80 MB，前端可优化空间本身有限；本版主要收益在**启动加载**（1.90 → 0.81 MB），安装包字节数基本持平 |
