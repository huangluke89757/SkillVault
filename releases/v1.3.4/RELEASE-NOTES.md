### 修复：自动更新装进嵌套目录、重复下载

- 修复「已是最新版本却反复下载安装包」的根因：安装器读取注册表 `InstallLocation` 时，若值被截断成 `D:SkillVault`（盘符后缺反斜杠），会按相对路径解析成 `安装目录\SkillVault`，导致新版本装进嵌套目录、旧版本没被覆盖
- 安装器现在会在初始化阶段补全这类路径并**写回注册表**，后续交互安装 / 静默升级读取到的都是正确路径；正常绝对路径、UNC、相对路径不受影响
- 自动更新新增版本一致性护栏：可下载 / 已下载版本与当前运行版本一致时，不再进入下载流程；启动时清理已过期的更新缓存（仍待安装的包不会删）

### 新增：版本更新弹窗「当前版本 / 最新版本」双区块

- 弹窗同时展示「当前版本 vX」与「最新版本 vY」两份更新介绍，当前版本也能看到自己这版改了什么
- 已是最新版本时，最新版本区块显示「您当前已装载最新版本👍，无需更新」，并隐藏下载 / 复制给 Agent 更新等操作；标题显示「SkillVault 已是最新版本」
- 当前版本 Release 取不到时降级为「暂无该版本的更新说明」；最新版本信息取不到时提示可重试，不阻塞界面
- 更新横幅在「有新版本但未下载」时不再误显示下载进度
